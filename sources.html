Methodology (auditable)

  1. Destination: Compared starred counts (Shanghai 51 vs Beijing 33 vs Guangzhou+Shenzhen 28) + metro + day-trip access; selected Shanghai as single base. See Executive Summary.
  2. Hotel ranking: District-level count of starred restaurants within ~60 min by metro from each hotel hub (2026 Guide districts + Shanghai Metro network). Estimates labelled “est.” — verify door-to-door before booking.
  3. Pricing: 2027 hotel rates not yet released → blank + UNVERIFIED. Proxies (Feb 2026) shown separately with source + date. Dining couple totals = per-person × 2; official prices preferred, estimates flagged with ranges.
  4. Booking windows: Synthesised Hotels.com (8–14 days), Booking.com (2–3 months), HotelsLove/KAYAK (4–8 weeks / last-minute) into a refundable-rate + re-price workflow with calendar dates.
  5. Social links: YouTube direct/search + TikTok/Instagram search URLs (platforms block stable direct links). Labelled as search URLs on every row.
  6. Verification: Every row has ≥1 source link. Blanks = “not confirmed from official source yet”. Irregularities logged in COORDINATION.md + Flagged page.
