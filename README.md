# ChinaFun2 — China Vacation & Michelin Cluster Planning Dashboard (Feb 15 – Mar 23, 2027)

An evidence-backed, line-by-line verified trip-planning repository and static GitHub Pages dashboard for a **2-adult couple vacation to China** within the **February 15, 2027 – March 23, 2027** travel window.

## Project Structure

- `index.html` — Dashboard landing page (KPIs, cluster comparison, combined 7-night hotel + 2-adult Michelin dining cost table)
- `executive-summary.html` — Executive Summary of key findings, recommended dates, and budget scenarios
- `hotels.html` — Ranked hotels by Michelin cluster reach (≤ 60 min by subway/bus), Queen/King bed & private bath verification, and 7-night verified pricing windows
- `michelin-restaurants.html` — Michelin Starred vs. Michelin Guide-Listed (Bib Gourmand & Selected) restaurants, 2-adult total cost, open days/hours/exceptions, official & social links (YouTube, TikTok, Instagram)
- `activities.html` — Curated activities within ≤ 60 minutes by subway/bus from ranked hotels, 2-adult cost, hours/exceptions, official & social links
- `questions-decisions.html` — Pre-decision questions, known vs. missing information matrix, and discovery plan
- `suggestions.html` — Dedicated section for decision-making & site improvement proposals (for review prior to implementation)
- `flagged-review.html` — Flagged irregularities, unverified fields ledger, and line-by-line source audit
- `COORDINATION.md` — Multi-session task board and verification log
- `docs/REPO_AUDIT.md` — Initial repository audit and official 2027 calendar/visa/Michelin macro verification
- `data/` — Structured JSON datasets backing all tables and automated checks
- `scripts/verify_site.py` — Line-by-line schema, link, and unverified-field integrity checker
