# China Trip Notes

A static, mobile-friendly, source-linked China travel research dashboard for two adults. Open `index.html` locally or publish the current branch root with GitHub Pages. No build step or API keys are required.

The research is a partial snapshot as of 25 November 2026. Michelin selections, opening hours, route durations, rates and availability change. Do not book based on this site without confirming the missing details listed on the Review page. Official links are supplied for each table row; independently produced videos are clearly labelled.

For coordination and verification notes, see [COORDINATION.md](COORDINATION.md).
